SZTECNO — sitio web liviano

Archivos:
- index.html
- styles.css
- assets/ (fotos entregadas)

FUNCIONAMIENTO
1. Abrí index.html en un navegador o subilo a cualquier hosting estático.
2. El catálogo se administra desde "Administrador" al pie.
3. Los productos se guardan en localStorage del navegador.
4. Se puede exportar/importar el catálogo en JSON.
5. "COMPRAR YA" abre WhatsApp con el producto y sus datos.

IMPORTANTE SOBRE SEGURIDAD
Este es un sitio estático. El panel admin usa SHA-256 y sessionStorage, pero el código de un sitio estático siempre puede inspeccionarse desde el navegador. NO debe considerarse una autenticación de servidor de alta seguridad.
Para publicar un panel realmente privado, conviene conectar el catálogo a un backend (por ejemplo Supabase/Firebase o un servidor propio) y usar autenticación del lado servidor.
